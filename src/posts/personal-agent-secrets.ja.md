## 賢いけれど、私のことは知らない

<img src="/assets/blog/personal-agent-secrets/01-context.webp" alt="コーヒーを手に空白のパソコン画面を見る人。メール、予定、写真は別々の箱に分かれたまま" width="1672" height="941" fetchpriority="high" decoding="async">

最近、Personal Agent をあれこれいじっている。

これまではデータベースや LLM、モデルの学習・推論に取り組んできた。考えるのは、もっと賢く、もっと速く、できれば安く、ということが多かった。

今、AI に頼みたいことは割と地味だ。朝になったら、今日の会議、返信すべきメール、昨日誰かに約束したことを教えてほしい。催促されてから思い出すのは、できれば避けたい。

一つずつ見れば、モデルはもうかなりできる。メールの要約や議事録の整理なら、小さくて安いモデルでも十分なことがある。

問題は、昨日私が何をしていたかを知らないことだ。

メールは Gmail、予定は Google Calendar、仕事の話は Slack。ほかにも WeChat、LINE、自分でも探せるか怪しいパソコンの中のファイルがある。

そうなると、毎日の作業はこうなる。まず私が自分の生活を整理して、そのあと AI に生活の整理を頼む。

このアシスタント、何のために雇ったんだろう。

## 本当に知ってもらうとなると、ちょっと怖い

<img src="/assets/blog/personal-agent-secrets/02-secrets.webp" alt="封筒をパソコンに渡そうとためらう人。写真や予定を結ぶ赤い糸が、一人の人間の輪郭を描いている" width="1672" height="941" loading="lazy" decoding="async">

もちろん、全部つなげてしまおうか、とも思う。

メールもカレンダーもチャット履歴も、自分で探してもらう。できれば、こちらが頼む前に必要なことを知らせてほしい。

想像しているうちは、とても便利そうだ。でも、アクセスを許可する画面まで来ると、手が止まる。

以前は、AI に何を話すかを自分で選んでいた。自発的に動いてもらうなら、毎回こちらが材料を渡すわけにはいかない。ただ、その材料には、わざわざ話すつもりのなかったことも混ざっている。

これまでも、情報はずいぶんネットに預けてきた。写真はここ、メールはあそこ、買い物の履歴はまた別。今度は、それを一つの Agent に全部つなげてほしいと思っている。

予定だけなら、水曜の午後は空いていない、で済む。メールや写真、会話まで組み合わせると、分かることは予定だけではなくなるかもしれない。

最近何をしているのかだけでなく、何をずっと後回しにしているのかまで、私より詳しくなりそうだ。

自分を理解してくれる助手はほしい。でも理解しすぎたら、たまには知らないふりをしてほしくなる気もする。

人間は面倒くさい。特に、ユーザーとしての私は。

## 見せることと、鍵を渡すこと

<img src="/assets/blog/personal-agent-secrets/03-permission.webp" alt="個人資料の棚から予定の入った引き出しだけを開け、持ち主が鍵を手に持っている" width="1672" height="941" loading="lazy" decoding="async">

モデルを作っていると、データはもう少し多くてもいいと思う。個人向け Agent では逆に、今回そこまで必要だろうか、と考えるようになった。

明日の会議を調整するなら、空いていない時間だけ分かれば十分かもしれない。すべての会議の中身まで読む必要はない。旅行の写真を一枚探すために、アルバム全体を送って、ずっと保存しておく必要もないはずだ。

それから、返信の下書きを作ることと、送信ボタンを押すことは違う。

下書きなら直せる。送ってしまったら、「さっきのはそういう意味ではなくて」と説明する仕事が増える。せっかく浮いた時間が、また消えていく。

誰が見られるのか。今回の処理が終わったあと何が残るのか。次も確認してくれるのか。使いたくなくなったら止められるのか。

以前なら地味だと思っていたことが、気になるようになった。

モデルのスコアを眺めていたはずが、今はアクセス権限を眺めている。研究の関心の移り変わりは、案外こんなものなのかもしれない。

情報は使ってほしい。でも、便利だからという理由で、最初から全部の扉を開けておきたくはない。

## モデルを替えるたびに、自己紹介はしたくない

<img src="/assets/blog/personal-agent-secrets/04-memory.webp" alt="写真やノートの入った思い出の箱を古いパソコンから新しいパソコンへ運ぶ人と、興味津々の猫" width="1672" height="941" loading="lazy" decoding="async">

Memory についても、少し引っかかっている。

ある AI と三年間話して、ようやく仕事や習慣、説明するのが面倒な背景まで覚えてもらえたとする。

そこに、もっと使いやすくて安いモデルが出てくる。

当然、替えたい。でも記憶が元のサービスの中にしかなかったら、移った先ではまた「はじめまして、私は……」から始まる。

モデルはアップグレードされたのに、自己紹介は再履修だ。

新しいスマホを買ったら、連絡先は古いスマホから持ち出せませんと言われるようなものだと思う。長年ためてきた情報は自分で管理して、モデルや Agent を替えるたびに人生ごと引っ越さずに済むといい。

最近、ローカルストレージやパーソナルクラウドに改めて関心が向いているのも、そのためだ。

もちろん、ローカルに置いたら無敵の金庫になるわけではない。機器は壊れるし、ソフトウェアに脆弱性はある。外部モデルを呼ぶなら、情報を送る場合もある。クラウドがあるからこそ便利な機能も多い。

何でも閉じ込めたいわけではない。今回何を送り、どこに残るのか。あとから停止・エクスポート・削除をしたくなったとき、実際にどこまでできるのか。それは知っておきたい。

助手を替えようとして初めて、自分の荷物を持って出られないと気づくのは困る。

## 心配しながら、手は「許可」に伸びている

<img src="/assets/blog/personal-agent-secrets/05-inbox.webp" alt="夜の机でメールの束をパソコンへ差し出しつつ、もう片方の手は停止ボタンのそばに置いている人。猫はもう眠っている" width="1672" height="941" loading="lazy" decoding="async">

もう少し先を考えると、Agent に渡すのは情報だけではなく、判断でもある。

毎日何十件も小さな用事を片づけてもらって、本当に全部確認するだろうか。百回問題がなければ、百一回目には、もうよく見ていない気がする。

自分ではチェックしているつもりで、ただ癖で「確認」を押しているだけにならないだろうか。

きっと、大きな決断を一回するわけではない。今日はメールの整理、明日は会議の調整。数か月たって気づいたら、一日の半分を Agent に決めてもらっていた、という感じかもしれない。

モデルを作る立場では、AI にもっと強くなってほしい。プロダクトを作る立場でも、本当に人の手間を減らしたい。

でも自分が使う側になると、急に注文が多くなる。理解してほしいけど、決めつけないでほしい。先回りしてほしいけど、勝手には決めないでほしい。全部任せたいけど、自分が口を出したいときには出せるようにしてほしい。

書いてみると、なかなか面倒な客だ。

今のところ、きれいな答えはない。ただ、たくさんの仕事を任せたあとでも、何をしているかを見られて、いつでも止められるといいと思う。

それで、今後も接続する情報を増やすのかというと……たぶん増やす。

プライバシーは真剣に考えるべきだ。でも受信箱を開いて、まだ返信していないメールを見るたびに、真剣に考えたはずの立場が少し揺らぐ。
